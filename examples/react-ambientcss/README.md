# react-ambientcss

A small audio-mixer panel — Bass/Volume/Treble knobs, a master slider, a
power switch and a reset button — built with `@ambientcss/components` and
styled with `@ambientcss/css`'s own classes (`amb-surface`, `amb-elevation-2`,
`amb-chamfer`, ...).

Vite + React + TypeScript.

## Run

```bash
pnpm install
pnpm dev
```
